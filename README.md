# זיכרון פלוס - משחקי זיכרון לגיל השלישי

אפליקציית PWA עם 10 משחקי זיכרון, חשיבה ואנגלית, מותאמת במיוחד לגיל השלישי.

## קישור לאפליקציה

**[https://ben9730.github.io/code-on-the-go/](https://ben9730.github.io/code-on-the-go/)**

## תכונות עיקריות

- 10 משחקי זיכרון, חשיבה ואנגלית מגוונים
- אתגר יומי מתחלף
- 4 רמות קושי (קל, בינוני, מאתגר, מומחה)
- משחקי אנגלית עם הקראה קולית (Text-to-Speech)
- הגדרות נגישות: גודל טקסט, ניגודיות גבוהה, צלילים ורטט
- מעקב ציונים ושיאים אישיים
- תמיכה בהתקנה כאפליקציה (PWA)
- עובד גם ללא חיבור לאינטרנט
- תזכורות הפסקה אחרי 20 דקות

## משחקים

| משחק | תיאור |
|------|--------|
| התאמת קלפים | מצאו את הזוגות התואמים |
| סדרת צבעים | זכרו את סדרת הצבעים |
| חידון מילים | ענו על שאלות ידע כללי (כולל טיימר ברמת מומחה) |
| מצאו את השונה | זהו את הפריט השונה בגריד (עד 5x4 ברמת מומחה) |
| זיכרון מספרים | זכרו את רצף המספרים |
| תמונה ומילה | התאימו תמונות למילים (עד 6 זוגות ברמת מומחה) |
| זיכרון צבעים | זכרו את סדר הצבעים |
| מהירות תגובה | בדקו את מהירות התגובה |
| אנגלית בתמונות | למדו מילים באנגלית עם תמונות |
| אנגלית בקול | הקשיבו למילים באנגלית ובחרו את התרגום |

## טכנולוגיות

- HTML5, CSS3, JavaScript (Vanilla)
- Progressive Web App (PWA)
- Service Worker לעבודה אופליין
- Web Audio API לצלילים
- Web Speech API להקראת מילים באנגלית
- Vibration API לרטט

## התקנה כאפליקציה

1. פתחו את הקישור בדפדפן Chrome / Safari
2. בכרום: לחצו על "התקנת אפליקציה" בסרגל הכתובות
3. באייפון: לחצו על "שתף" > "הוסף למסך הבית"
